\# Инструкции проекта «Пещера Теней»



\## Продукт



Простая стильная 2D-игра для детей около 10 лет. Вид сверху, мрачная пещера без жестокости, крови и скримеров. Целевые устройства: компьютер и телефон.



Основной цикл: исследовать пещеру, искать цветные ключи, открывать двери и сундуки соответствующего цвета и добираться до выхода.



Постоянные правила игры:



\* фонарь бесконечный;

\* свет помогает видеть, но позднее будет выдавать игрока;

\* ключ не расходуется;

\* ключ открывает все двери и сундуки своего цвета на текущем этаже;

\* при переходе на новый этаж ключи сбрасываются;

\* на этаже используется не больше двух цветов;

\* страж медленно преследует игрока;

\* безопасная комната временно усыпляет и удаляет стража;

\* бой заменён редкой защитной световой вспышкой.



\## Технологии



\* Phaser 4.2.1;

\* TypeScript 7.0.2 в strict-режиме;

\* Vite 8.1.5;

\* Arcade Physics;

\* Git и GitHub Desktop.



Используй API установленного Phaser 4.2.1. Не переноси неподтверждённые примеры Phaser 3. Для RenderTexture/DynamicTexture в Phaser 4 учитывай обязательный render() после буферизованных операций.



\## Архитектура



Модульный монолит вокруг Phaser Scenes:



\* domain — чистые правила и данные без Phaser и DOM;

\* world — тонкие Phaser-объекты и представление мира;

\* systems — отдельные игровые системы;

\* scenes — связывание систем и управление состоянием сцены.



Phaser управляет циклом, рендерингом, вводом и физикой.



Не добавляй без прямого требования:



\* собственный GameLoop или Renderer;

\* React;

\* ECS;

\* DI-контейнер;

\* сервер и сеть;

\* новые библиотеки;

\* универсальные абстракции «на будущее».



\## Экономный рабочий процесс



\* Выполняй только одну небольшую задачу за раз.

\* Читай AGENTS.md и только файлы, относящиеся к задаче.

\* Не перечитывай все документы в docs/, если это прямо не требуется.

\* Не используй субагентов, Swarm или Goal для обычных задач.

\* Не ищи версии пакетов и документацию без необходимости.

\* Не запускай dev-сервер: пользователь держит его в отдельном PowerShell.

\* После изменений запускай только npm run typecheck и npm run build.

\* Не создавай и не обновляй зависимости без разрешения.

\* Не удаляй файлы и не откатывай пользовательские изменения.



\## Git



Разрешены только read-only команды:



\* git status;

\* git diff;

\* git log.



Запрещены commit, push, создание или слияние веток. Коммит и push выполняет пользователь через GitHub Desktop.
