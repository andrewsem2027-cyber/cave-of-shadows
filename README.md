# cave-of-shadows
A 2D stealth exploration game built with Phaser 4

«Пещера Теней» — спокойная 2D-игра для детей с видом сверху: три этажа
пещеры, цветные ключи и двери, коллекционные кристаллы, защитная световая
вспышка и страж, который реагирует на свет фонаря.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install         # установить зависимости
npm run dev         # development-сервер: http://localhost:5173/
npm run typecheck   # проверка типов TypeScript
npm run build       # production-сборка в dist/
npm run preview     # локальный просмотр production-сборки
```

Игра рассчитана на горизонтальное положение телефона.

## Игра

- Главное меню: новая игра, продолжение, коллекция кристаллов, управление.
- Три этажа: «Вход в пещеру», «Затопленные тоннели», «Сердце глубины».
- Шесть цветов ключей: ключ не расходуется и открывает все объекты
  своего цвета на текущем этаже; при переходе ключи сбрасываются.
- Шесть коллекционных кристаллов в необязательных местах; коллекция
  хранится в локальном сохранении (localStorage).
- Световая вспышка (Space): останавливает стража на 3 секунды, заряды
  находятся в сундуках (максимум 3).
- Пауза: Esc, P или экранная кнопка.

## Управление

- WASD / стрелки — движение (на телефоне — D-pad);
- F — фонарь;
- Space — световая вспышка;
- Esc / P — пауза;
- ключи и кристаллы подбираются автоматически.
